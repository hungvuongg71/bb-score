# Developer Skills & Project Features

## 🏀 Basketball Domain Knowledge

- **Team Management:** Khả năng tùy chỉnh tên Team Home và Team Away thông qua Input.
- **Score Logic:** Hiểu quy tắc tính điểm đặc thù của bóng rổ (1, 2, 3 điểm).
- **Match State:** Nút "Reset" để bắt đầu hiệp mới hoặc trận mới.

## 💻 Technical Skills

- **Adaptive UI:** - Mobile-first design cho màn hình dọc.
  - Media Queries tối ưu cho màn hình ngang (iPad/Tablet/TV) để treo ở sân bóng.
- **Digital Aesthetics:** - Tạo hiệu ứng LED Glow bằng CSS `text-shadow`.
  - Thiết kế Score Box với viền neon.
- **State Management:** - Xử lý DOM nhanh chóng để cập nhật điểm số realtime (không lag).
- **UX/UI:** - Nút bấm lớn (Touch-friendly) để người cầm bảng điểm dễ dàng thao tác mà không cần nhìn bàn phím.
